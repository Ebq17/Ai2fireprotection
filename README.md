# Ai2fireprotection – Website

Statische Einzelseiten-Website für Ai2fireprotection (vorbeugender Brandschutz, Mainz & Rhein-Main).

## Lokal öffnen

Einfach `index.html` im Browser öffnen — keine Build-Schritte, keine Abhängigkeiten.

## Live hosten (GitHub Pages)

1. Repo-Einstellungen → **Pages**
2. Branch **main**, Ordner **/(root)** auswählen
3. Speichern — die Seite ist danach unter `https://<username>.github.io/<repo>/` erreichbar

## Inhalte anpassen

Alle Inhalte (Texte, Kontaktdaten, Leistungen) stehen direkt im HTML in `index.html`. Der Farb-Akzent lässt sich zentral über die CSS-Variable `--accent` in der `.page`-Klasse anpassen.
